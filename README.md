### Java: working with lambdas, streams and Spring Framework
### Project developed in the first course of the Alura Advanced with Java training

### Project objectives
- Create the ScreenMatch project from scratch using the Spring Framework, initially with the command line;
- Use Maven as a dependency manager;
- Use Jackson to deserialize data;
- Model the application's abstractions through records, classes, attributes and methods;
- Consume an API to search for data from series, seasons and episodes;
- Work with collections and understand in depth the use of lambda functions;
- Learn about the Streams API and apply intermediate operations such as filter, sorted, map, flatMap, peek, among others;
- Transform streams into new lists and maps;
- Generate customized statistics in the application.
